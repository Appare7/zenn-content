# verify-article の検査項目

| 検査 | 基準 | 直し方 |
| --- | --- | --- |
| slug | ファイル名が a-z0-9-_ の12〜50文字 | ファイル名を変える(公開済みならURLが変わるので要相談) |
| title | 70文字以内 | 副題を削る |
| topics | 5個以内 | 優先度の低いものを外す |
| images | 参照先が存在し、1枚3MB以下 | `sips --resampleWidth 1600 <png>` |
| captions | 画像行の直後が `*キャプション*` | 1行で書く |
| leftovers | `<!-- fig` `@@` などの作業用マーカーが無い | 消す |
| private | 研究プロジェクトの固有名、裏側のベンダー名が無い | 一般的な言い方に置き換える |
| details | `:::details` と `:::message` の開閉が対 | 閉じの `:::` を足す |
